Analisar, Traduzir e Integrar API no Projeto Vitrine Digital
O objetivo deste plano é transformar o projeto estático atual em uma aplicação web funcional, totalmente traduzida para Português (pt-BR), integrada à Fake Store API e com sistema de login funcional para testes.

User Review Required
IMPORTANT

A Fake Store API não permite salvar dados permanentemente (ex: novos produtos adicionados ou novos cadastros não ficarão salvos no banco deles, apenas retornarão sucesso na hora). A simulação será feita via JavaScript no frontend para fins de teste e demonstração. Além disso, a Fake Store API fornece produtos gerais (eletrônicos, joias, roupas). As imagens e textos das vitrines serão substituídas por esses dados.

Proposed Changes
1. Tradução Global e Ajustes de Interface
Todos os arquivos HTML serão traduzidos do inglês para o português do Brasil (pt-BR).

Textos de navegação, botões, rodapé, placeholders e alertas.
Alteração da moeda de Dólar ($) para Real (R$).
